# LOG_meanw — усреднение / интерполяция LoRA-весов вместо выбора шага по pLDDT

Модель: ESMFold2 + ProteinTTT_MSA, лучший конфиг `M_alpha256`. Набор: **18 CAMEO-мишеней** (решение пользователя).
Лимит: **50 GPU-ч** (пользователь), аккаунт OPEN-37-88.

## Мотивация (2026-10-08)

На бенчмарке (80 белков, lDDT vs PDB): последний шаг 0.519, шаг по pLDDT 0.570, лучший возможный шаг 0.596.
Почти 0.03 lDDT теряется на отборе. Кривая «фиксированный шаг» плоская и шумная (0.50–0.52 на шагах 5–20),
то есть шаги одного белка сильно шумят → усреднение весов может убрать шум без отбора.
Референс на CAMEO (E15 в `LOG.md`): шаг 0 — 0.545, выбор по pLDDT — 0.664.

## План

TTT = `scripts/ESMFold2/cameo_M_alpha256.yaml` без изменений (SGD lr 0.08, bs8×ags32, clip 0.75, LoRA r64/α256,
20 шагов, MSA neighbors, mask 0.2, fold 3/50, без early stopping). LoRA-веса всех 21 шагов держатся в RAM;
после 20-го шага — 15 дополнительных фолдов на белок (тот же seed, 3/50):

| группа | имя в `samples.tsv` | что это |
|---|---|---|
| A | `avg_18_20`, `avg_16_20`, `avg_11_20`, `avg_1_20` | точное среднее ΔW = up·down по шагам (конкатенация рангов) |
| B | `avg_top5_plddt` | то же по 5 шагам с лучшим pLDDT |
| C | `avgAB_11_20` | наивное среднее `up` и `down` отдельно |
| D | `interp_{last,sel,avg10}_t{25,50,75}` | W₀ + t·ΔW от шага 20 / pLDDT-выбранного шага / `avg_11_20` |

Сравнение на той же траектории: `step_last`, `step_sel_plddt` (правило ProteinTTT), `step_oracle`;
плюс `pool_sel_plddt` — выбор по pLDDT из пула «21 шаг + 15 вариантов».
Метрика: foldseek lDDT vs `cameo/pdbs`. Seeds 0 и 1 (n = 18, шум большой).

## Код

Ветка `meanw` (worktree `.claude/worktrees/meanw`):
- `proteinttt/models/esmfold2.py`: `keep_step_states: true` → `_ttt_eval_step` складывает LoRA-веса шага в `self.step_states` (CPU).
- `scripts/ESMFold2/weight_avg.py` — TTT + варианты; `run_weight_avg.sh` — SLURM; `eval_weight_avg.py` — оценка.
- Выход: `cameo/esmfold2_wavg/seed{0,1}/<id>/{step_N,<вариант>}.pdb`, `samples.tsv`, `ttt_log.tsv`.

Проверка на CPU: ΔW из конкатенации рангов == среднее up·down (allclose) — OK.
